Порядок подобран по одному правилу: **каждая фаза заканчивается чем-то, чем можно пользоваться.**

Оценки — в вечерах (2–4 часа) при работе с Claude Code.

## Фаза 0 — разведка боем · 1 вечер

**Специально идёт первой.** Здесь проверяются три вещи, каждая из которых способна убить проект, и лучше узнать это сегодня, а не через два месяца.

- [x] `wails3 doctor` зелёный, Go 1.25+, Xcode CLT на месте
- [x] Шаблон Wails v3 + Vite + React + TypeScript, окно открывается — `oak-go/phase0/cm6`
- [x] **Дымовой тест FTS5**: `modernc.org/sqlite`, `CREATE VIRTUAL TABLE t USING fts5(x, tokenize='trigram')`, вставка, поиск по подстроке из середины слова — `oak-go/phase0/fts5`, зелёный. Trigram находит подстроки внутри слов, кириллица регистронезависима вместе с «ё», 10k заметок по ~2 КБ индексируются за 2 с при размере файла 47 МБ. **Схему из SPEC §5.1 придётся поправить:** `content=''` без `contentless_delete=1` не позволяет удалить строку, не зная старого содержимого, а при удалении файла его уже нет
- [x] **CodeMirror 6 с vim-режимом в WKWebView.** Проверить руками: русская раскладка, мёртвые клавиши, автозамена кавычек macOS, системная проверка орфографии, выделение мышью, `Esc` из insert-режима — `oak-go/phase0/cm6`. Системный ввод заглушён насовсем (`spellcheck`, `autocorrect`, `autocapitalize` — off), вим работает с `Vim.langmap()` для ЙЦУКЕН
- [x] ~~**Подписанный и нотаризованный `.dmg`, запущенный на втором маке.**~~ **Отменено, сертификат Apple не покупается.** Один мак, приложение только для себя. Локально собранный бинарник не получает `com.apple.quarantine`, Gatekeeper его не проверяет, а ad-hoc подписи от линкера Go достаточно для запуска arm64 на Apple Silicon. Сценарий «показать другу» решается доступом к репозиторию; если понадобится передать готовый `.app` — `xattr -dr com.apple.quarantine Tasker.app` на принимающей стороне
- [x] Вместо подписи: собрать `.app`, убедиться, что запускается. **Сделано 2026-08-20 в фазе 3:** `wails3 task package` даёт `bin/tasker.app` (19 МБ) с `CFBundleIdentifier: dev.tasker.app` и **автоматической ad-hoc подписью** — сертификат Apple не понадобился, как и планировалось. Запуск из бандла проверен
- [x] Пин точной версии Wails в `go.mod` — `v3.0.0-beta.9`, та же, что проверялась пробами фазы 0. `go mod tidy` тянул beta.11, понижено вручную

**Готово, когда:** все пункты дали ответ. Если CM6 в WKWebView ведёт себя плохо с кириллицей — это повод пересмотреть стек **до** того, как написан код, а не после.

**К вопросу подписи вернуться в фазе 8**, на глобальном хоткее: TCC привязывает выданные разрешения к хешу кода, у ad-hoc подписи он меняется на каждой сборке, поэтому Accessibility придётся выдавать заново после каждой пересборки. Лечится бесплатным сертификатом по Apple ID, без Developer Program. Неудобство, а не блокер.

## Фаза 1 — ядро · 2–3 вечера

Чистый Go, без Wails, без UI, с тестами. Твоя территория.

- [x] `internal/vault`: чтение/запись `.md`, атомарно (временный файл → `fsync` → `rename`) — `vault.go`: `Open`, `Load`, `Save`, `Create`. Пути проверяются через `filepath.EvalSymlinks` и `filepath.Rel`, а не по префиксу строки. `Save` не перезаписывает неизменённую заметку и проставляет `updated` только при настоящей правке
- [x] Frontmatter через `goccy/go-yaml` с сохранением неизвестных полей и порядка ключей. **Тест на round-trip обязателен и пишется первым** — `frontmatter.go` поверх AST, а не структур. Гарантия: неизменённый заголовок отдаётся байт в байт, правка одного ключа не трогает соседей, порядок и комментарии на месте
- [x] Разделение frontmatter и тела своим кодом (~20 строк), без сторонней зависимости — `document.go`, разделитель ищется по правилу Obsidian/Jekyll, горизонтальная линия в теле не ломает разбор
- [x] ULID через `oklog/ulid`, slug с транслитом кириллицы, разрешение коллизий имён — `id.go`, `slug.go`, `create.go`. Имя занимается через `os.Link`, а не «проверить и создать»: приложение и `tasker-mcp` — разные процессы, и между проверкой и созданием второй успевает занять имя. Таблица транслита своя, без зависимости; спорные буквы: ё→e, х→h, ц→c, щ→sch, ъ и ь выбрасываются — **менять после появления файлов в vault нельзя**
- [x] `internal/index`: схема из SPEC §5.1, WAL, полный скан и инкрементальный по `(path, mtime, size)` — `schema.go`, `index.go`, `record.go`, `scan.go`. mtime хранится в наносекундах: правка той же длины в ту же секунду иначе не отличается. Скан не падает из-за одной битой заметки, собирает такие в `ScanResult.Failed`. Переезд файла не считается удалением — id тот же, ссылки не рвутся
- [x] Парсер языка запросов → SQL, с тестами на каждую форму из SPEC §8.5 — `query.go` (разбор) и `search.go` (компиляция и выполнение). Отрицание снимается токенизатором, где видно, внутри кавычек минус или снаружи. Неизвестный префикс — обычный текст, а вот значения закрытых перечислений проверяются. `book:` сравнивает со слэшем, а не по префиксу строки, и экранирует шаблоны LIKE
- [x] `internal/watcher`: fsnotify, дебаунс 300 мс, реестр «своих» записей с проверкой mtime, периодическая сверка — `watcher.go`. **Формулировка «только по папкам» из спеки не выполнима:** fsnotify сам открывает дескриптор на каждый файл, зато благодаря этому видит правку на месте. Замеры и второе, более неприятное следствие — в SPEC §5.3
- [x] `internal/gitstore`: init, автокоммит с дебаунсом, `log --follow`, diff — `gitstore.go`, `autocommit.go`. Запись через go-git (на инкрементальном коммите он быстрее системного git: 18 мс против 118 мс на 2000 заметках), чтение истории и diff — системным git, потому что `--follow` в go-git нет вовсе. **Окно автокоммита отсчитывается от первой правки, а не от последней:** формулировка спеки «после последнего изменения» при непрерывной работе не закрывается никогда и ломает обещание из SPEC §10
- [x] CLI-утилита `cmd/tasker-scan` для проверки руками: строит индекс по папке и отвечает на запросы — флаги `-limit`, `-trashed`, `-no-scan`. Запрос разбирается до открытия vault, чтобы опечатку показать сразу. Сквозные тесты поверх настоящих vault и индекса лежат рядом с ним

**Готово, когда:** `go test ./...` зелёный, а `tasker-scan ~/Notes "тест tag:работа"` находит нужное в папке с сотней файлов. **Проверено 2026-08-20 на 102 файлах:** полный скан 77 мс, повторный 1 мс, запрос 270 мкс, индекс 572 КБ. Остаются `internal/watcher` и `internal/gitstore`.

## Почему порядок именно такой

В варианте с TypeScript оболочка появляется первой, потому что там она тривиальна. Здесь наоборот: **фаза 0 намеренно вынесена в самое начало как разведка**, потому что три главных риска этого стека — бета Wails, WKWebView под CodeMirror и подпись macOS — все проверяются за один вечер, и все три дешевле обнаружить сейчас.

Фазы 1 и 2 — чистый Go, полностью в твоей зоне уверенности, и уже дают работающий главный сценарий. JS начинается только с фазы 3, когда данные уже надёжны и покрыты тестами.
