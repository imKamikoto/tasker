# Tasker — бриф для дизайна

Локальный редактор заметок-как-задач под macOS. Заметки — `.md` файлы в папке, офлайн, один пользователь. Клавиатура важнее мыши. Отдельная фишка: AI-агент через MCP пишет в ту же папку, такие заметки помечены `origin: agent`.

## Экран

Три колонки, разделители тянутся: сайдбар 216px · список 320px · редактор. Верхние 42px — зона перетаскивания окна, там ничего кликабельного.

**Сайдбар:** «Активные» · «Все заметки» · дерево НОУТБУКОВ со счётчиками, кнопкой `+` и меню `⋯` (вложенный/переименовать/удалить) · ТЕГИ со счётчиками · «Корзина».

**Список:** поиск (`tag:баг status:active -отрицание "фраза"`) · сортировка заголовок/создано/изменено · строки **строго 104px** (виртуализация): звезда, заголовок, 2 строки превью, метаполоса из даты, `3/7` чеклиста, статус-бейджа и тегов · мультивыбор.

**Редактор:** заголовок · метаполоса (ноутбук, статус, бэклинки, индикатор сохранения) · цветные чипы тегов + автокомплит + палитра на 14 цветов · CodeMirror с vim и его строкой статуса.

**Уже существующие состояния:** пусто · выбрано несколько · ничего не найдено · ошибка · «файл изменён снаружи» с выбором версии · заметка в корзине · оверлей переноса · инлайн-ввод имени.

## Функционал

Статусы `none/active/onHold/completed/dropped` · закрепление · корзина с восстановлением · теги с цветами · дерево ноутбуков · поиск-язык · сортировки · массовые операции · шоткаты (`j/k`, `Enter`, `p`, `m`, `Cmd+D`, `Cmd+Backspace`, `Cmd+N`, `Cmd+Ctrl+1..5`) с перебиндом через json.

## Палитра

Тёмная «дубовая», HSL:

```
bg 30° 25% 6% · bg-elevated 30° 25% 10% · bg-shadow 30° 25% 3%
oak 30° 35% 64%
  oak-100 28° 22% 17%  ховер
  oak-200 28° 26% 31%  выделение, бейджи
  oak-400 29° 28% 23%  выбранная строка
  oak-600 31° 42% 74%  ссылки
  oak-800 34° 38% 84%  заголовки
fg 0° 0% 90% · fg-muted 0° 0% 85%/62% · border 34° 40% 94%/10%
green 152° 50% 58% · yellow 48° 95% 60%
```

Шрифты: системный для интерфейса, `SF Mono` для текста заметки. Теги — 14 оттенков по кругу, S≈40%, L≈65%.

## Ограничения

Только macOS, только тёмная тема. Обычный CSS с переменными — никаких UI-китов и CSS-in-JS. Высота строки списка фиксирована. Любой новый шоткат не должен конфликтовать с vim.

## Где слабо — есть что придумать

Пустой vault без приглашения · **заметки от агента визуально никак не выделены**, хотя это главная фишка · нет правого клика · при мультивыборе справа просто счётчик вместо панели действий · статусы неотличимы друг от друга на глаз · нет фидбека при drag&drop · метаполоса строки перегружена · нет экрана настроек и списка шоткатов.

## Заложить место на будущее

Превью markdown с синхронным скроллом · палитра команд `Cmd+K` · ссылки `[[` и панель бэклинков · картинки · шаблоны · история версий с diff · быстрая заметка отдельным окном.
