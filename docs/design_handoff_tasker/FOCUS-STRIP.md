# Индикатор фокуса колонки — блочная ASCII-рампа

Полоса в титульной строке окна, показывает, в какой из трёх колонок сейчас клавиатурный фокус. Макеты: раздел T12 в `Tasker.dc.html` (12a сайдбар, 12b список, 12c редактор).

## Геометрия

- Живёт в верхних 11px титульной строки (высота строки 38–42px, она же drag-зона окна). Высоту у контента не отнимает.
- Рампа центрируется по своей колонке: `position:absolute; left:0; right:0; top:0; height:11px`, внутри flex с `justify-content:center` и `overflow:hidden`.
- Шрифт: `11px/11px "SF Mono", ui-monospace, Menlo`, `white-space:nowrap`.

## Символы

Длина рампы пропорциональна ширине колонки:

| Колонка | Ширина | Строка | letter-spacing |
|---|---|---|---|
| Сайдбар | 216–232px | `░▒▓█████▓▒░` (11) | 1px |
| Список | 300–320px | `░▒▓███████████▓▒░` (17) | 1px |
| Редактор | остаток | `░▒▓█████████████████▓▒░` (23) | 1px |
| Любая неактивная | — | `···············` (15) | 2px |

Цвет активной — акцент (`hsl(210 28% 64%)` в тёмной, `hsl(210 42% 36%)` в светлой). Неактивной — `hsla(0 0% 100% / .10)` в тёмной, `hsla(0 0% 0% / .12)` в светлой.

Если колонка шире 560px, брать вариант на 23 символа и не растягивать дальше: рампа читается как метка, а не как заполнение ширины.

## Подписи

Под рампой опциональные подписи колонок: `10px` моно, `letter-spacing: .16em`, uppercase, `padding-top: 7px`. Активная — `hsl(0 0% 85%)`, неактивная — `hsl(0 0% 26%)`. У сайдбара подписи нет, там системный светофор. Подписи можно выключить — рампа самодостаточна.

## Поведение

- Переключение фокуса: `⌃⇧H` / `⌃⇧L` (влево/вправо), а также `Enter` (список → редактор) и `Esc` (редактор → список), клик по колонке.
- **Без анимации.** Полоса перерисовывается мгновенно; плавный переход на такой мелкой графике читается как подтормаживание.
- Когда окно неактивно, все три колонки показывают неактивный вариант (точки).

## Полоса — не единственный признак фокуса

Рампа поддерживается локальными признаками внутри колонки, иначе фокус теряется на большом экране:

- **Сайдбар:** выбранный ноутбук получает `box-shadow: inset 2px 0 0 accent`, глиф и счётчик — акцентом.
- **Список:** поле поиска получает рамку `accent alpha .5` и мигающий курсор; выбранная строка — фон `--bg-selected` (17%) и полосу акцента слева 2px. Без фокуса выбранная строка остаётся на `--bg-hover` (13%) без полосы.
- **Редактор:** в тексте появляется блочная каретка акцентом.

## Реализация

```
FocusRing = 'sidebar' | 'list' | 'editor'
```

Одно значение в глобальном состоянии, полоса — чистая функция от него и от ширин колонок. Ширины уже есть в состоянии (разделители перетаскиваются), так что выбор длины рампы — простой `switch` по колонке, а не расчёт по пикселям.
