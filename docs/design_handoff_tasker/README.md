# Handoff: Tasker — локальный редактор заметок-как-задач под macOS

## Overview

Tasker — однопользовательское офлайн-приложение под macOS. Заметки хранятся обычными `.md` файлами в выбранной папке. Отдельная особенность: AI-агент через MCP пишет в ту же папку; такие заметки помечены во фронтматтере `origin: agent` и визуально отличаются в интерфейсе.

Дизайн покрывает: основной трёхколоночный экран (тёмная и светлая темы), 12 состояний и окон (пустая папка, пустой поиск, мультивыбор, корзина, конфликт файла, перенос, ⌘K, теги, инлайн-переименование, drag&drop, меню статуса, тосты) и экран настроек «Внешний вид».

## About the Design Files

Файлы в этом бандле — **дизайн-референсы, сделанные в HTML**. Это прототипы, показывающие внешний вид и поведение, а не продакшн-код для копирования. Задача — воспроизвести эти макеты в целевом окружении приложения (SwiftUI/AppKit для нативного mac-приложения, либо Electron/Tauri + React, если проект веб-стековый), используя принятые в кодовой базе паттерны. Если окружения ещё нет — выбрать стек самостоятельно; макеты от этого не зависят.

Редактор в макетах нарисован статикой, в реализации это **CodeMirror 6** с vim-режимом и его строкой статуса (как указано в исходном брифе).

## Fidelity

**High-fidelity.** Цвета, типографика, размеры и отступы финальные. Токены закреплены в `PALETTE.md`. Высота строки списка — строго 104px (виртуализация), ширины колонок фиксированные. Воспроизводить пиксель-в-пиксель.

Производные: `--accent-soft` = акцент с alpha .14 (фон плашек), `--accent-line` = alpha .5 (рамки, пунктиры).
Правило для кастомных акцентов: тёмная тема S 18–28% / L 58–70%, светлая — тот же оттенок при L 26–44%. Ярче не пускать: приложение для многочасовых сессий.

**Семантика**

```
status-hold     hsl(44 55% 58%)   глиф ‖     светлая hsl(38 70% 32%)

```

**Теги** — 14 оттенков по кругу (hue 8, 34, 60, 86, 112, 138, 164, 190, 216, 242, 268, 294, 320, 346): тёмная S 40% L 65%, светлая S 55% L 40%. Фон чипа — тот же цвет с alpha .16.

**Типографика**
- Интерфейс: `-apple-system, BlinkMacSystemFont, "SF Pro Text"`.
- Моно: `"SF Mono", ui-monospace, Menlo` — тело заметки, метаполосы, шоткаты, статусы, прогресс-бары, номера строк.
- Шкала: заголовок заметки 26/34 600; заголовок строки списка 14/20 600; превью 12/17; метаполоса 11/16 моно; секции сайдбара 10 моно, letter-spacing .14em, uppercase; тело редактора 13/22 моно.

**Радиусы**: окно 10–11, карточки/поповеры 7–11, кнопки и строки меню 4–6, чипы и бейджи 3.
**Тени**: окно `0 24px 70px rgba(0,0,0,.6)`; модалка `0 28px 70px rgba(0,0,0,.7)`; поповер `0 18px 44px rgba(0,0,0,.65)`; тост `0 16px 36px rgba(0,0,0,.55)`; призрак drag `0 14px 30px rgba(0,0,0,.6)`.
**ASCII-акценты**: разделители — `repeating-linear-gradient(90deg, var(--border) 0 2px, transparent 2px 4px)`, высота 1px; прогресс чеклиста — символы `▓` и `░`; вертикальные разделители метаполосы — символ `│` цветом `--fg-faint`.

### 3. Настройки → Внешний вид (макет T6, `6a` тёмная / `6b` светлая)

Окно 820×600, слева навигация 196px (Внешний вид, Папка и файлы, Редактор, Шоткаты, Агент, О программе), верхние 42px — drag-зона со светофором. Справа заголовок «Внешний вид» и две сгруппированные карточки в стиле System Settings (фон `--bg-elevated`, радиус 10, строки разделены линиями, слева подпись 150px + пояснение, справа контрол):

1. **Оформление** — три превью 92×60 (Авто — половина светлая/половина тёмная, Светлая, Тёмная), выбранное обведено `0 0 0 3px accent`; подписи снизу.
2. **Акцент** — шесть кружков 24px + пунктирный «свой»; выбранный обведён двойным кольцом; пояснение «Красит выделение, ссылки, чеклисты и метку агента».
3. **Прозрачность фона** — слайдер 260px, дорожка 4px, заполнение акцентом, ручка 15px на `--bg-elevated`; справа значение в процентах.
4. **Размытие** — такой же слайдер.
5. **Экономия** — тумблеры «Отключать прозрачность на батарее» (вкл) и «Дизер-текстура на панелях» (выкл). Тумблер 32×18, радиус 9, вкл — акцент.

**Формула прозрачности:** alpha панели = 1 − (значение слайдера); `backdrop-filter: blur(N)`, где N = процент размытия × 0.6px (100% → 60px). Сайдбар и список используют это значение, **редактор всегда на 30 п.п. плотнее** списка. На батарее (при включённом тумблере) прозрачность и блюр отключаются целиком.

## Interactions & Behavior

- **Клавиатура важнее мыши.** `j`/`k` — перемещение по списку, `Enter` — фокус в редактор, `Esc` — обратно в список, `p` — закрепить, `m` — перенести, `t` — теги, `⌘N` — новая, `⌘D` — дублировать, `⌘⌫` — в корзину, `⌘K` — палитра команд, `⌘F` — поиск, `⌃1..5` — статусы (none / active / onHold / completed / dropped). Все шорткаты перебиндиваются через `keymap.json`; конфликты с vim-режимом подсвечиваются в настройках красным и блокируются.
- **Мультивыбор**: `⇧`+клик — диапазон, `⌘`+клик — точечно, `Esc` — снять. При выборе ≥2 в списке появляется нижняя панель действий (7c), правая колонка при этом показывает не счётчик, а ту же панель в развёрнутом виде.
- **Правый клик** доступен на строке списка, ноутбуке и теге.
- **Drag&drop**: перетаскивание строк на ноутбук в сайдбаре, при мультивыборе тянется вся пачка; цель подсвечивается, после дропа — тост с «Отменить».
- **Файловый watcher**: при внешнем изменении открытого файла — модалка 7e. Если заметка не открыта, список обновляется молча, а изменения от агента помечаются «не прочитано» до открытия.
- **Автосохранение** с дебаунсом 400 мс; индикатор в метаполосе переходит `сохранение… → ● сохранено HH:MM`.
- **Анимации**: сдержанные. Поповеры и модалки — fade + scale .98→1, 120 мс, ease-out. Тосты — сдвиг снизу 8px, 160 мс. Подсветка цели drag — 80 мс. Смена темы — без анимации.
- **Hover** на строках: `--bg-hover`; на кнопках — фон светлеет на один шаг шкалы.

## State Management

- `vault`: путь к папке, статус доступа (нет прав / папка пуста / ок), watcher.
- `notes[]`: id (путь файла), заголовок, превью, mtime/ctime, `status`, `pinned`, `tags[]`, `notebook`, `origin: human | agent`, `unread`, прогресс чеклиста `{done, total}`, `deletedAt`.
- `notebooks[]`: дерево, счётчики, состояние раскрытия.
- `tags[]`: имя, hue (0–13), счётчик.
- `query`: разобранный поисковый запрос (токены `tag:`, `status:`, отрицания, фразы) + ошибки парсинга для 7b.
- `selection`: активная заметка + множество выбранных.
- `sort`: поле и направление.
- `ui`: открытая модалка (`move | palette | conflict | tagPicker | rename | null`), тосты, состояние drag.
- `settings`: тема (auto/light/dark), акцент, прозрачность, размытие, экономия на батарее, keymap; хранить в `~/.tasker/settings.json`, тему по умолчанию брать из системы.
- Переходы: изменение статуса/тегов/переносы пишутся во фронтматтер файла и сразу отражаются в списке (оптимистично, с откатом по ошибке записи).

## Assets

Внешних ассетов нет. Вся графика — текст (глифы `◆ ▶ ‖ ✓ ✕ ★ ☆ ▚ ▓ ░ │ └ ▸ ▾ ≡ ⌕`), CSS-градиенты и рамки. Светофор окна рисуется системой (в макетах — три кружка `#ff5f57`, `#febc2e`, `#28c840`).

## Files

- `Tasker.dc.html` — все макеты. Разделы: **T12** индикатор фокуса колонки, **T11** его отвергнутые варианты, **T10** иконка, **T9/T8** её поиск, **T5** основной экран (тёмная и светлая), **T7** состояния и окна (7a–7l), **T6** настройки, **T4** архив с подбором акцента. Открывается в браузере как есть.
- `PALETTE.md` — закреплённые токены, правила акцентов и прозрачности.
- `FOCUS-STRIP.md` — индикатор фокуса колонки: символы, геометрия, поведение.
- `icon/` — PNG-набор иконки 1024→16 (+ светлый вариант) и `icon/README.md` с геометрией и командой сборки `.icns`.
- `DESIGN-BRIEF.md` — исходный бриф с функциональными требованиями и списком заделов на будущее (превью markdown с синхронным скроллом, `Cmd+K`, `[[ссылки]]` и бэклинки, картинки, шаблоны, история версий с diff, быстрая заметка отдельным окном).
