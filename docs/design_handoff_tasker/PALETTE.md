# Tasker — закреплённая палитра

Две стандартные темы: нейтральная серая шкала. Цвет появляется только в акценте, статусах и тегах.
Акцент по умолчанию — **Сталь**. «Дуб» из первого брифа переезжает в кастомные темы (файл в `~/.tasker/themes`).

## Тёмная (по умолчанию)

```
--bg            hsl(0 0% 5%)     фон списка и редактора
--bg-sidebar    hsl(0 0% 2%)
--bg-elevated   hsl(0 0% 11%)    поля ввода, статус-бар, поповеры
--bg-hover      hsl(0 0% 13%)
--bg-selected   hsl(0 0% 17%)    выбранная строка (+ полоса акцента слева 2px)
--bg-badge      hsl(0 0% 24%)
--fg            hsl(0 0% 92%)
--fg-heading    hsl(0 0% 96%)
--fg-muted      hsl(0 0% 62%)
--fg-dim        hsl(0 0% 45%)
--fg-faint      hsl(0 0% 30%)    разделители `│`, неактивные глифы
--border        hsla(0 0% 100% / .10)
```

## Светлая

```
--bg            hsl(0 0% 100%)
--bg-sidebar    hsl(0 0% 96%)
--bg-elevated   hsl(0 0% 95%)
--bg-hover      hsl(0 0% 94%)
--bg-selected   hsl(0 0% 90%)
--bg-badge      hsl(0 0% 86%)
--fg            hsl(0 0% 15%)
--fg-heading    hsl(0 0% 8%)
--fg-muted      hsl(0 0% 42%)
--fg-dim        hsl(0 0% 52%)
--fg-faint      hsl(0 0% 72%)
--border        hsla(0 0% 0% / .12)
```

## Акценты

Правило: в тёмной S 18–28% / L 58–70%, в светлой тот же оттенок при L 26–44%. Ярче не делать — режет глаза на длинных сессиях.

| Имя | Тёмная | Светлая |
|---|---|---|
| Графит | hsl(0 0% 62%) | hsl(0 0% 45%) |
| **Сталь** (default) | hsl(210 28% 64%) | hsl(210 42% 36%) |
| Шалфей | hsl(150 20% 58%) | hsl(150 32% 28%) |
| Лаванда | hsl(258 24% 70%) | hsl(258 32% 44%) |
| Хаки | hsl(64 18% 62%) | hsl(64 40% 26%) |
| Глина | hsl(18 30% 62%) | hsl(18 42% 38%) |

Производные: `--accent-soft` = тот же цвет с alpha .14 (фон плашек), `--accent-line` = alpha .5 (рамки).

## Семантика

```
--status-active     hsl(150 30% 55%)  ▶      светлая: hsl(150 40% 28%)
--status-hold       hsl(44 55% 58%)   ‖      светлая: hsl(38 70% 32%)
--status-done       --fg-muted        ✓
--status-dropped    --fg-faint        ✕
--danger            hsl(9 55% 60%)           светлая: hsl(9 60% 42%)
--agent             --accent          ◆ + пунктирная полоса слева 3px
```

Теги — 14 оттенков по кругу: тёмная S 40% L 65%, светлая S 55% L 40%.

## Прозрачность

Сайдбар и список: `background: color-mix(...)` с alpha = 1 − прозрачность из настроек (по умолчанию 55%), `backdrop-filter: blur(N)` где N = размытие 0–100% → 0–60px. Редактор всегда на 30 п.п. плотнее списка. На батарее прозрачность отключается.

## Типографика

Интерфейс — системный (-apple-system). Моно — SF Mono: метаполосы, шоткаты, статусы, прогресс `▓▓▓░░░░`, тело заметки. ASCII только в акцентах: пунктирные разделители, рамки, прогресс-бары.
